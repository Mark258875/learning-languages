# Spelling → Sound Rules (De l'écrit à l'oral)

Companion to [Pronunciation](pronunciation.md), which covers the individual sounds, liaison,
elision and intonation. This sheet answers a different question: **given a written word, how do
I know what to say?** French spelling is old but regular: ~95 % of words follow the rules below.

---

## The Three Golden Rules

1. **Final consonants are silent** by default (*chat, grand, vous, parlent*).
   Usually pronounced: **c, r, f, l** — mnemonic **CaReFuL** (*sac, mur, neuf, sel*).
   Big exception inside the exception: **-er** (infinitives, *boulanger, premier*) = /e/, *r* silent.
2. **Final mute *e* is silent** but makes the consonant before it audible:
   *grand* /ɡʁɑ̃/ → *grande* /ɡʁɑ̃d/ ; *petit* /pə.ti/ → *petite* /pə.tit/.
   This is how you hear masculine vs feminine.
3. **Every written vowel (group) is one syllable**, no vowel reduction, stress on the **last
   syllable of the group**: *u-ni-ver-si-**té***. The phrase, not the word, carries the stress.

## Final Consonants in Detail

| Letter(s) | Default | Pronounced in… | Silent in… |
|---|---|---|---|
| **-s, -x, -z** | silent | *fils* /fis/, *os* (sg.) /ɔs/, *tous* (pronoun) /tus/, *plus* (+) /plys/, *six, dix* (isolated) | *dans, temps, prix, nez, tous les* (adj.) /tu/, *plus* (neg.) /ply/ |
| **-t, -d** | silent | *huit, sept, net, ouest, but* /byt/ (or /by/), *août* /ut/, *sud* | *petit, chat, grand, pied, nord* |
| **-p, -b, -g** | silent | *cap, stop, snob, club, gag, zigzag* (loanwords) | *trop, beaucoup, coup, plomb, long, sang, vingt* |
| **-c** | /k/ | *sac, lac, parc, sec, avec, chic, public* | *blanc, franc, estomac, tabac, porc, escroc* ; *-nc* usually silent |
| **-r** | /ʁ/ | *mur, cher, hiver, fer, fier, amer, mer* (monosyllables & *-ier/-er* adjectives) | **-er** verbs & job nouns: *parler, boulanger, premier, léger* |
| **-f** | /f/ | *neuf, chef, vif, actif, œuf* /œf/ | *clef* /kle/, *nerf*, plurals *œufs* /ø/, *bœufs* /bø/ |
| **-l** | /l/ | *sel, il, mal, seul, avril* | *gentil* /ʒɑ̃.ti/, *outil* /u.ti/, *fusil*, *sourcil* ; **-il** after vowel = /j/: *travail, soleil* |
| **-n, -m** | nasalise the vowel | never as a consonant (except loanwords: *amen, album* /al.bɔm/) | — |
| **-t** in numbers | — | *sept* /sɛt/, *huit* /ɥit/ (except before consonant: *huit jours* /ɥi ʒuʁ/) | *vingt* /vɛ̃/, *cent* /sɑ̃/ (liaison: *vingt ans* /vɛ̃.t‿ɑ̃/) |

**Numbers change with context**

| | Isolated | + consonant | + vowel |
|---|---|---|---|
| **six** | /sis/ | /si/ (*six livres*) | /siz/ (*six ans*) |
| **dix** | /dis/ | /di/ | /diz/ |
| **huit** | /ɥit/ | /ɥi/ | /ɥit/ |
| **neuf** | /nœf/ | /nœf/ | /nœf/ ; /nœv/ only in *neuf ans, neuf heures* |
| **vingt** | /vɛ̃/ | /vɛ̃/ | /vɛ̃t/ (*vingt euros*) ; *vingt-deux* /vɛ̃t.dø/ keeps the t |
| **cent** | /sɑ̃/ | /sɑ̃/ | /sɑ̃t/ (*cent ans*) |
| **quatre-vingts** | /ka.tʁə.vɛ̃/ | same | /…vɛ̃z/ (*quatre-vingts ans*), never /t/ |

**plus** — /plys/ when it means "more" and ends the phrase (*j'en veux plus*), /ply/ before a
consonant (*plus grand*), /plyz/ in liaison (*plus intéressant*), /ply/ always when negative
(*je ne fume plus*). **tous** — /tus/ as a pronoun (*ils sont tous là*), /tu/ as an adjective
(*tous les jours*).

## Vowels: Spelling → Sound

| Spelling | IPA | Examples | Notes |
|---|---|---|---|
| **a, à** | /a/ | *la, patte, là* | *â* slightly darker /ɑ/ in careful speech: *pâte* |
| **é, -er, -ez, -ai** (final) | /e/ | *été, parler, parlez, j'ai* | closed "ay" without the glide |
| **è, ê, ei, ai, -et, -ais, -ait, -aient** | /ɛ/ | *mère, tête, neige, fait, paquet, je parlais* | open "eh" |
| **e** + pronounced consonant in same syllable | /ɛ/ | *elle, mer, sept, avec, est* | closed syllable → open vowel |
| **e** open syllable / before single consonant + vowel | /ə/ | *le, de, petit, samedi* | the droppable schwa |
| **e** + double consonant / **e** in *-ess-, -ett-* | /ɛ/ | *belle, terre, adresse* | |
| **e** before final silent consonant(s) | /e/ or /ɛ/ | *pied* /pje/, *les, des, mes* /le/ | |
| **i, î, y** | /i/ | *ici, île, style* | |
| **o** (closed syllable), **-o-** | /ɔ/ | *porte, bonne, pomme* | |
| **o** (final / before /z/), **ô, au, eau** | /o/ | *vélo, rose, tôt, haut, eau* | |
| **ou, oû** | /u/ | *vous, où, goût* | |
| **u, û** | /y/ | *tu, sûr* | never /u/ |
| **eu, œu** (final / before /z/) | /ø/ | *feu, deux, heureuse, nœud* | |
| **eu, œu** (closed syllable) | /œ/ | *peur, seul, sœur, jeune* | |
| **oi, oî, oy-** | /wa/ | *moi, boîte, voyage* /vwa.jaʒ/ | |
| **oin** | /wɛ̃/ | *loin, coin* | |
| **ui** | /ɥi/ | *huit, nuit, lui* | |
| **ill** after consonant | /ij/ | *fille, famille, billet* | exceptions /il/: *ville, mille, tranquille, Lille* |
| **-il / -ill-** after vowel | /j/ | *travail, soleil, feuille, grenouille, œil* | *ail* /aj/, *eil* /ɛj/, *euil* /œj/, *ouil* /uj/ |
| **-ay-, -oy-, -uy-** | vowel + /j/ | *payer* /pe.je/, *voyons* /vwa.jɔ̃/, *ennuyer* | |

**Loi de position** (the rule behind é/è, o/ɔ, ø/œ): in an **open** syllable (ends in a vowel)
the vowel is **closed** /e o ø/; in a **closed** syllable (ends in a consonant) it is **open**
/ɛ ɔ œ/. *sot* /so/ vs *sotte* /sɔt/, *peu* /pø/ vs *peur* /pœʁ/, *les* /le/ vs *l'aile* /lɛl/.
Spelling overrides it only with *è/ê* (always /ɛ/) and *ô/au/eau* (always /o/).

### Nasal vowels: when *n / m* nasalise

*n* or *m* nasalises the vowel **only when it ends the syllable** (followed by a consonant or
the end of the word). Before a vowel or when doubled, it is a plain consonant.

| Nasal | Not nasal |
|---|---|
| *an, ans, en, temps, chambre* /ɑ̃/ | *année* /a.ne/, *ami*, *homme* /ɔm/ |
| *vin, pain, plein, faim, sympa* /ɛ̃/ | *fine* /fin/, *peine* /pɛn/, *aime* /ɛm/ |
| *bon, nom, ombre* /ɔ̃/ | *bonne* /bɔn/, *nommer* /nɔ.me/ |
| *un, parfum, brun* /œ̃/ (≈ /ɛ̃/ in Paris) | *une* /yn/, *brune* /bʁyn/ |
| *-ien* = /jɛ̃/: *bien, rien, chien* | *-ienne* = /jɛn/: *parisienne* |
| *-en* in *examen, agenda* /ɛ̃/ | *-ent* on verbs: silent (*ils parlent*) |

Masculine → feminine denasalises: *bon* /bɔ̃/ → *bonne* /bɔn/, *américain* /ɛ̃/ → *américaine* /ɛn/,
*paysan* /ɑ̃/ → *paysanne* /an/. Same in liaison: *bon ami* /bɔ.n‿a.mi/, *un ami* /œ̃.n‿a.mi/.

### Semivowels
*i, u, ou* + vowel become glides: *i* → /j/ (*bien, pied*), *u* → /ɥ/ (*lui, huit, nuit*),
*ou* → /w/ (*oui, Louis*). After a consonant cluster they stay vowels: *crier* /kʁi.je/,
*trouer* /tʁu.e/.

## Consonants: Spelling → Sound

| Spelling | IPA | Rule | Examples |
|---|---|---|---|
| **c** + a, o, u, consonant | /k/ | hard | *café, école, cru, classe* |
| **c** + e, i, y | /s/ | soft | *ce, ici, cycle, France* |
| **ç** | /s/ | forces soft before a, o, u | *ça, garçon, reçu, français* |
| **g** + a, o, u, consonant | /ɡ/ | hard | *gare, gomme, grand* |
| **g** + e, i, y | /ʒ/ | soft | *âge, gilet, gymnase* |
| **gu** + e, i | /ɡ/ | *u* silent, keeps hard g | *guerre, guide, langue* |
| **ge** + a, o | /ʒ/ | *e* silent, keeps soft g | *mangeons, Georges, pigeon* |
| **s** initial / after consonant | /s/ | | *sac, absent, penser* |
| **s** between vowels | /z/ | | *rose, maison, poison* |
| **ss** | /s/ | | *poisson, adresse* |
| **x** initial *ex-* + vowel | /ɡz/ | | *examen, exemple, exister* |
| **x** elsewhere | /ks/ | | *taxi, expliquer, luxe* ; *soixante, Bruxelles, dix* → /s/ |
| **ch** | /ʃ/ | | *chat, chercher* ; Greek words /k/: *chaos, orchestre, chœur* |
| **gn** | /ɲ/ | | *montagne, gagner, ligne* |
| **qu** | /k/ | *u* silent | *qui, quatre, quel* ; /kw/ in *aquarium, équateur* |
| **ph** | /f/ | | *photo, philosophie* |
| **th** | /t/ | never /θ/ | *thé, théorie, mathématiques* |
| **h** | silent | *h muet* allows liaison/elision, *h aspiré* blocks them | *l'homme* vs *le héros, la haine, le haut* |
| **ti** + vowel (in *-tion, -tie, -tiel*) | /sj/ | | *nation, patience, essentiel, démocratie* ; /tj/ after s: *question, moitié, amitié* |
| **w** | /w/ or /v/ | loanwords | *week-end* /wi.kɛnd/, *wagon* /va.ɡɔ̃/ |
| **-ll-** | /l/ | except *ill* rules above | *aller, belle* |
| **r** | /ʁ/ | uvular, always same | *rue, Paris, mer* |
| **p, t, k** | unaspirated | no puff of air (unlike English) | *papa, thé, quatre* |

## Verb Endings: What You Actually Hear

The endings are the most regular part of the whole system. Learn this table once and every
tense becomes predictable.

### Present tense

| Singular | Plural |
|---|---|
| **-e / -s / -x** (je) → silent: *je parle, je finis, je peux* | **-ons** (nous) → /ɔ̃/: *parlons* /paʁ.lɔ̃/ |
| **-es / -s / -x** (tu) → silent: *tu parles, tu finis, tu veux* | **-ez** (vous) → /e/: *parlez* /paʁ.le/ |
| **-e / -t / -d** (il) → silent: *il parle, il finit, il attend* | **-ent** (ils) → **silent**: *parlent* /paʁl/ ; **-ont** only in *sont, ont, vont, font* → /ɔ̃/ |

So a regular **-er** verb has 3 spoken forms: /paʁl/ ×4, /paʁ.lɔ̃/, /paʁ.le/.
A regular **-ir** verb has 4 because of *-iss-*: *finis, finit* /fi.ni/ ; *finissons* /fi.ni.sɔ̃/,
*finissez* /fi.ni.se/, *finissent* /fi.nis/ (the *-ent* is silent, the *ss* before it is not).
A regular **-re** verb also has 4: *attends, attend* /a.tɑ̃/ (the *d* is silent, so the vowel
stays nasal) ; *attendons* /a.tɑ̃.dɔ̃/, *attendez* /a.tɑ̃.de/, *attendent* /a.tɑ̃d/.

> ⚠️ *il attend* /a.tɑ̃/ vs *ils attendent* /a.tɑ̃d/ — for **-re** and **-ir** verbs the plural
> **is** audible, because the stem consonant surfaces before the silent *-ent*. For **-er** verbs
> it never is.

### The /e/ vs /ɛ/ family (imparfait, futur, conditionnel)

| Spelling | Sound | Forms |
|---|---|---|
| **-er, -ez, -é, -ée, -és, -ai** | /e/ | *parler, parlez, parlé, j'irai* (futur), *je parlai* (passé simple) |
| **-ais, -ait, -aient, -et** | /ɛ/ | *je parlais, il parlait, ils parlaient* (imparfait), *j'irais* (conditionnel) |

Hence *je parlerai* (futur) /e/ vs *je parlerais* (conditionnel) /ɛ/ is the only difference
between "I will" and "I would". Many Parisians merge them; in careful speech keep it.
*parlais, parlait, parlaient* are identical: /paʁ.lɛ/.

### Futur & conditionnel endings

| Singular | Plural |
|---|---|
| *je parler**ai*** /e/ ; *tu parler**as*** /a/ ; *il parler**a*** /a/ | *nous parler**ons*** /ɔ̃/ ; *vous parler**ez*** /e/ ; *ils parler**ont*** /ɔ̃/ |
| *je parler**ais*** /ɛ/ ; *tu parler**ais*** /ɛ/ ; *il parler**ait*** /ɛ/ | *nous parler**ions*** /jɔ̃/ ; *vous parler**iez*** /je/ ; *ils parler**aient*** /ɛ/ |

The *-r-* of the futur/conditionnel stem is always pronounced: *parlerai* /paʁ.lə.ʁe/ (or
/paʁl.ʁe/ with the schwa dropped).

### Past participles
*-é* /e/ (*parlé*), *-i* /i/ (*fini*), *-u* /y/ (*vendu, vu*), *-is* /i/ (*pris, mis*),
*-it* /i/ (*dit, écrit*), *-ert* /ɛʁ/ (*ouvert*), *-eint* /ɛ̃/ (*peint*). Feminine agreement makes
the consonant audible: *pris* /pʁi/ → *prise* /pʁiz/, *dit* /di/ → *dite* /dit/, *ouvert* → *ouverte* /u.vɛʁt/.

### Imperative
Same as present without the *-s* on *tu* for -er verbs (*parle !*), and the *-s* is restored
before *y / en* purely for liaison: *vas-y* /va.zi/, *parles-en* /paʁ.lə.zɑ̃/.

### Homophones you must resolve from context

| Sound | Written forms |
|---|---|
| /paʁ.le/ | *parler, parlé, parlez, parlai* |
| /paʁ.lɛ/ | *parlais, parlait, parlaient* |
| /paʁl/ | *parle, parles, parlent* |
| /fi.ni/ | *fini, finis, finit* |
| /a/ | *a* (has), *à* (to) ; /u/ *ou* (or), *où* (where) ; /sɔ̃/ *son, sont* ; /ɔ̃/ *on, ont* |

## Syllables & Rhythm in Practice

- French syllables prefer to **end in a vowel**: *a-ni-mal*, *u-ni-ver-si-té*. A single
  consonant between vowels goes with the **next** syllable: *ca-fé, pe-tit*.
- Across words this becomes **enchaînement**: *il est arrivé* → /i.lɛ.ta.ʁi.ve/.
- Only the **last syllable of the phrase** is stressed, slightly longer, never louder. Every
  other syllable is equal. Nothing is reduced to "uh" as in English *about*.
- The schwa /ə/ of *je, le, de, ne, ce, me, te, se* and unstressed *e* inside words drops
  whenever this does not create three consonants in a row: *je ne sais pas* → /ʒən.sɛ.pa/,
  *samedi* /sam.di/, *maintenant* /mɛ̃t.nɑ̃/, but *une petite* keeps /pə/ (*n-p-t*).

## Self-test (answers below)

Transcribe in IPA, then say aloud:
1. *ils finissent* 2. *vous attendez* 3. *elle est américaine* 4. *six euros, six livres*
5. *je mangerais* / *je mangerai* 6. *un bon vin blanc* 7. *le gentil garçon*
8. *nous voyageons* 9. *quatre-vingts ans* 10. *il prend, ils prennent*

### Answers

1. /il fi.nis/ 2. /vu.z‿a.tɑ̃.de/ 3. /ɛ.lɛ.t‿a.me.ʁi.kɛn/ 4. /si.z‿ø.ʁo/, /si livʁ/
5. /ʒə mɑ̃ʒ.ʁɛ/ conditionnel, /ʒə mɑ̃ʒ.ʁe/ futur 6. /œ̃ bɔ̃ vɛ̃ blɑ̃/ (no liaison: *bon* + consonant)
7. /lə ʒɑ̃.ti ɡaʁ.sɔ̃/ (*-il* silent, *ç* = /s/) 8. /nu vwa.ja.ʒɔ̃/ (*-ge-* keeps /ʒ/)
9. /ka.tʁə.vɛ̃.z‿ɑ̃/ 10. /il pʁɑ̃/ (nasal, *d* silent), /il pʁɛn/ (denasalised, *nn* + silent *-ent*)
