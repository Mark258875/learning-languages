# French Pronouns (Pronoms)

The single biggest source of B1→B2 errors. Work through the order-and-position rules until
they're automatic.

---

## Subject Pronouns

*je, tu, il/elle/on, nous, vous, ils/elles* — see [Grammar](grammar.md#subject-pronouns).
Cannot be dropped (French is not pro-drop) and cannot be stressed — for emphasis you add a
**stressed pronoun** (below): *Moi, je pense que…*

---

## Direct Object (COD) — *le / la / l' / les*

Replaces a noun with **no preposition** ("whom / what?").
- *Tu vois **le film** ?* → *Tu **le** vois ?*
- *J'aime **cette chanson**.* → *Je **l'**aime.*
- *Il connaît **mes parents**.* → *Il **les** connaît.*
- *le* can also stand for a whole idea / adjective: *— Tu es prêt ? — Je **le** suis.*

## Indirect Object (COI) — *lui / leur*

Replaces **à + a person** ("to whom?"). Same *me/te/nous/vous* as COD in the other persons.
- *Je parle **à Marie**.* → *Je **lui** parle.*
- *Il écrit **à ses collègues**.* → *Il **leur** écrit.*

> ⚠️ Verbs that look indirect in English but take a **direct** object in French:
> *écouter qqn, regarder qqn, attendre qqn, chercher qqn, payer qqch* →
> *Je **l'**écoute* (not *lui*).
> And the reverse — French **à**, English direct: *téléphoner à, répondre à, obéir à,
> ressembler à, plaire à* → *Je **lui** téléphone.*
> With *penser à qqn*, *tenir à qqn*, *faire attention à qqn* you keep **à + stressed pronoun**:
> *Je pense **à elle**.*

## *y* and *en*

### *y*
- = **à + a thing / place** (not a person): *Je pense **à mon travail**.* → *J'**y** pense.*
  *Tu vas **à Paris** ?* → *Tu **y** vas ?*
- Fixed: *il **y** a*, *on **y** va*, *ça **y** est*, *je m'**y** connais*.

### *en*
- = **de + a thing / place**: *Il revient **de Lyon**.* → *Il **en** revient.*
  *Tu es sûr **de ça** ?* → *Tu **en** es sûr ?*
- = a **partitive / indefinite quantity** (*du, de la, des, un, deux, beaucoup de…*):
  *Tu veux **du café** ?* → *Tu **en** veux ?*
  *J'ai **deux frères**.* → *J'**en** ai deux.* (keep the number!)
  *Il a **beaucoup de travail**.* → *Il **en** a beaucoup.*
- No past-participle agreement with *en*: *Des erreurs ? J'**en** ai fait.* (not *faites*)

## Order of Object Pronouns (before the verb)

Only two can normally stack. Order:

| 1 | 2 | 3 | 4 | 5 |
|---|---|---|---|---|
| me | | | | |
| te | le | lui | | |
| se | la | | y | en |
| nous | les | leur | | |
| vous | | | | |

- *Il **me le** donne.* — He gives it to me.
- *Je **le lui** ai dit.* — I told him/her (it).
- *Tu **m'en** veux ?* — Are you cross with me? / *Donne-**m'en**.*
- *Il **les y** a emmenés.* — He took them there.
- Mnemonic: **me/te/se/nous/vous** → **le/la/les** → **lui/leur** → **y** → **en**
  ("**MTV** before **L**, **L** before **lui**, then **y**, then **en**").

**Position:**
- Normal: **before** the conjugated verb — *Je **ne le lui** ai pas donné.*
- With an infinitive: before the **infinitive** — *Je vais **le lui** donner.*
  *Tu peux **m'en** parler.*
- **Affirmative imperative** only: **after** the verb, hyphenated, order **le/la/les – moi/toi/lui/nous/vous/leur – y – en**:
  *Donne-**le-moi**. Allons-nous-**en**. Parle-**lui-en**.*
  (Negative imperative keeps the normal pre-verb order: *Ne **me le** donne pas.*)

## Stressed / Disjunctive Pronouns (*pronoms toniques*)

*moi, toi, lui, elle, soi, nous, vous, eux, elles*

Used:
- for **emphasis**: ***Moi**, je reste. **Eux**, ils partent.*
- **after a preposition**: *avec **toi**, chez **eux**, sans **elle**, à cause de **lui**, pour **nous***.
- after **c'est / ce sont**: *C'est **moi**. Ce sont **eux**.*
- in **comparisons** and after *que*: *plus grand que **toi***, *comme **elle***.
- **alone / short answers**: *— Qui veut du café ? — **Moi** !*
- with *-même(s)* = "-self": *Je l'ai fait **moi-même**.*
- *soi* = generic/impersonal (*chacun pour **soi***, *rester chez **soi***).
- double subject: *Marc et **moi** (, nous) partons demain.*

## Relative Pronouns

Link a clause to a noun (the *antecedent*).

| Pronoun | Role | Example |
|---|---|---|
| **qui** | subject of the relative clause | *L'homme **qui** parle est mon prof.* |
| **que (qu')** | direct object of the relative clause | *Le livre **que** je lis est passionnant.* |
| **où** | place or time | *La ville **où** je suis né ; le jour **où** on s'est rencontrés.* |
| **dont** | replaces **de + …** (complement of verb, noun or adjective) | *Le film **dont** je t'ai parlé. Un outil **dont** j'ai besoin. La femme **dont** le fils est médecin.* |
| **lequel / laquelle / lesquels / lesquelles** | after a preposition, usually for things | *Le stylo **avec lequel** j'écris. Les raisons **pour lesquelles** il est parti.* |
| **à / de + lequel** → **auquel / duquel** etc. | contracted | *Le projet **auquel** je pense. Le sujet **à propos duquel** on débat.* |
| **qui** after a preposition, for people | *La personne **avec qui** je travaille ; l'ami **à qui** je pense.* |

> ⚠️ *que* vs *qui* is about **grammatical role**, not human/thing: if the next word is a verb
> → *qui*; if the next word is a subject → *que*.
> Past participle agrees with a preceding *que*-object: *La lettre **que** j'ai écrit**e**.*

### *ce qui / ce que / ce dont / ce à quoi* — "what" (no specific antecedent)
- *Je ne sais pas **ce qui** se passe.* (subject)
- *Dis-moi **ce que** tu veux.* (object)
- *Voilà **ce dont** j'ai besoin.* (de)
- *C'est **ce à quoi** je pensais.* (à)
- Summarising a whole clause: *Il est arrivé en retard, **ce qui** m'a agacé.*

---

## Demonstrative Pronouns — *celui / celle / ceux / celles*

"the one(s)". Never stands alone — must be followed by *-ci/-là*, *de …*, or a relative clause.
- *Quel livre ? **Celui-ci** ou **celui-là** ?*
- *Ma voiture et **celle de** mon frère.*
- ***Ceux qui** veulent partir peuvent y aller.*
- Neutral: **ce / c'** (*c'est*), **ceci, cela, ça** — *Ça m'énerve. Cela dit, … Ceci explique cela.*

## Possessive Pronouns — *le mien …*

| | m. sing. | f. sing. | m. pl. | f. pl. |
|---|---|---|---|---|
| mine | le mien | la mienne | les miens | les miennes |
| yours (tu) | le tien | la tienne | les tiens | les tiennes |
| his/hers/its | le sien | la sienne | les siens | les siennes |
| ours | le nôtre | la nôtre | les nôtres | les nôtres |
| yours (vous) | le vôtre | la vôtre | les vôtres | les vôtres |
| theirs | le leur | la leur | les leurs | les leurs |

- *C'est ton sac ? — Non, c'est **le sien**.*
- Note the circumflex: *nôtre / vôtre* (pronoun, /o/) vs *notre / votre* (adjective, /ɔ/).
- "a … of mine" = *un(e) de mes …* or *à moi*: *un ami **à moi***.

## Indefinite Pronouns (high-frequency)

| Pronoun | Meaning / note |
|---|---|
| **on** | we (informal) / people / someone — always 3sg verb, see [Grammar](grammar.md) |
| **quelqu'un / personne** | someone / no one (*ne … personne*) |
| **quelque chose / rien** | something / nothing (*ne … rien*) — adj. attached with *de*: *quelque chose **de** bien* |
| **quelques-un(e)s** | a few (of them): *J'en ai lu **quelques-uns**.* |
| **chacun(e)** | each one: ***Chacun** son goût.* |
| **tout / tous / toutes** | everything / all of them (pronoun *tous* → final *s* pronounced /tus/) |
| **plusieurs** | several |
| **certains / d'autres** | some / others |
| **n'importe qui / quoi / lequel / où / quand / comment** | any(one/thing/…) at all |
| **l'un(e) … l'autre / les uns les autres** | one … the other / one another |
